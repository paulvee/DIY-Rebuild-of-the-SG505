This is a repository to hold the relevant information for a DIY rebuild of the Tektronix SG505 sine wave oscillator.

The code for the frequency counter display can only be used with the Virtual Studio Code environment. If you decide to use the Arduino IDE, you will have to make some changes to the code and libraries.

Details about the project can be found on my Blog here:
https://www.paulvdiyblogs.net/2025/11/the-diy-sg505-mains-power-supply.html
https://www.paulvdiyblogs.net/2025/09/diy-rebuild-of-tek-sg505-v3.html
Note that there are several more posts for the earlier versions, this can all be found following the links above.

Info for the BOM's. There is a BOM in the manufacturing data file, but that is automatically generated from the KiCad data. 
Use the ones that are in the main project directory, because they are more current and have additional information.
